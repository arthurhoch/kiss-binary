KissBinary

Zero-dependency Java 17+ binary IO for explicit primitive formats, memory-mapped reads, header validation, and predictable errors. Part of the KISS Java Libraries family.

Getting Started API Overview Maven Central GitHub 
BinaryWriter writer = BinaryWriter.create();
writer.writeMagic("KB");
writer.writeVersion(1);
writer.writeInt(42);
writer.writeLong(1000L);

byte[] data = writer.toByteArray();

BinaryReader reader = BinaryReader.from(data);
reader.expectMagic("KB");
reader.expectVersion(1);

Small API

Read and write primitives, primitive arrays, magic bytes, and versions without schema or object serialization.

Zero Dependencies

The production artifact depends only on the Java standard library and targets Java 17 or newer.

Measured Paths

JMH benchmarks cover scalar IO, arrays, memory-mapped reads, and Rinha-shaped binary access patterns.
